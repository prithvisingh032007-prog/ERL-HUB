PROJECT: ERL-HUB
Post-Earthquake Multi-Agency Emergency Relief Logistics Hub

SUBJECT: Object-Oriented Programming Using C++
PAPER CODE: CIC-211

LANGUAGE: C++
STANDARD: C++17

HOW TO COMPILE:
g++ -std=c++17 ERL_HUB.cpp -o ERL_HUB

HOW TO RUN:
Windows:
ERL_HUB.exe

Linux:
./ERL_HUB

DESCRIPTION:
A menu-driven emergency relief logistics management
system for managing relief supplies, transport vehicles,
cargo allocation, emergency dispatch, medical triage,
and transit records.
